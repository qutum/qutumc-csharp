## qutum.parser.Lexier

词法解析器，读取byte流，产出`Lexi`流，行列定位，DFA算法

以`key`标识词，每词为一或多组，每组并列一或多分支，每分支为一或多字节（或单选字节、转义）
- 依次匹配每组，组内匹配某分支，贪婪匹配
- 组第一分支可空：其他分支不匹配时匹配空分支
- 组可选重试：各分支不匹配时，略过一字节（此字节在匹配结果中，且报错）重试组
- 分支可选循环：此分支匹配后循环此组
- 字节可选重复：此字节可连续匹配多个
- 第一组固定为重试 且分支不可重复（避免匹配其他词）

默认单选字节为 编码32-126及 `\t\n\r`
- 转义：`\s`空格 `\t\n\r` `\d`数字 `\x`十六进制 `\a`字母 `\b`任意字节 `\B`编码128以上

`key`重复的词，视为不同词分别解析，但产出的`lexi`之`key`相同

## qutum.parser.Synter<br>qutum.parser.SerMaker

语法解析器，读取`Lexer`，基于LR算法，产出语法树；
语法解析生成器，读取文法，产出语法解析参数

以`name`标识生成式，每生成式并列无或多分支，每分支为无或多元语，每元语为一词`key`或一生成式`name`

冲突解决
- 移位、化简 同一或多分支，则为冲突
- 每分支可选：拒绝、左结合、右结合、同前分支
- 拒绝：此分支涉及的冲突，均不解决
- 左解法：移位或化简 在更后的分支，同一分支化简（左结合）
- 右解法：移位或化简 在更后的分支，同一分支移位（右结合）
- 同前分支：解决方式、前后 均与前分支相同

错误恢复
- 每分支可选错误恢复，最后元语为词`key`，作为恢复词
- 解析错误时，已匹配主词的（或无主词）可恢复分支，作为候选
- 错误词前 尝试插入恢复词，恢复等待恢复词的分支
- 寻找后方恢复词，恢复在解析栈更近 且在更后的分支

错误信息
- 只选择已匹配主词的（或无主词）分支
- 优先至劣后：有标题、范围更广、匹配元语中点更后、在更后的分支
- 选择一或二分支产出错误信息，更多分支产出...
- 读取超出文法尾 产出错误信息

语法节点
- 每分支可选一元语词为主词，主词存入节点
- 每一元语为 一节点或一节点串，分支与元语作为上下节点,形成语法树
- 每分支可选节点：产出、忽略、左提升、右提升
- 产出：产出一节点，为各元语下节点的上节点
- 忽略：各元语成一节点串，作为上节点一元语处理
- 左提升：把最左元语提升为 左节点或串，产出一右节点，为其余元语的上节点，左右节点成串
- 右提升：把最右元语提升为 右节点或串，产出一左节点，为其余元语的上节点，左右节点成串
- 节点`name` 可不同于生成式
